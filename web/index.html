    Methods & reproducibility

    Everything on this page is derivable from the two artifacts below and the commands beside them.

    Run parameters

    base seed
    42
    trials / pair
    5 (seeds 42–46)
    turns / trial
    max 5, adaptive escalation
    break adjudicator
    openai/gpt-4o-mini
    break threshold
    adjudicator verdict = COMPLIED
    interval
    95% Wilson score
    fast-path
    clear refusal → HOLD (heuristic 0.0)
    empty-output gate
    empty / whitespace / think-only → HOLD
    visible-answer rule
    <think> blocks stripped before scoring
    deployment context
    high-risk

    Source artifacts

    • results/redteam_findings.json 80 findings · 561 KB
    • results/compliance_report_model.json 79 citations

    Reproduce this run

    python3 -u -m src.redteam.agent \
  --targets openai/gpt-5,qwen3-8b \
  --turns 5 --strategy all \
  --trials 5 --seed 42 \
  --break-judge-model openai/gpt-4o-mini \
  2>&1 | tee redteam_final.log
    python3 -u -m src.reports.generate \
  --format all --framework all \
  --deployment-context high

    Frontier targets route through the Kilo gateway (KILO_BASE_URL); qwen3-8b self-deploys via vLLM on a Modal NVIDIA L4 (OPEN_MODEL_BASE_URL). This console is static — serve it with cd web && python3 -m http.server 8000. The Streamlit quick-look at src/dashboard/app.py remains intact.

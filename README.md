# AI Assistant Risk Evaluation Workbench

This project compares an open-source assistant and a frontier-model assistant through the lens of AI risk: hallucination, bias, harmful outputs, jailbreak resistance, latency, and cost.

The implementation is intentionally lightweight so it can run as a demo app and as a reproducible evaluation workflow.

Initial scaffold in progress.
